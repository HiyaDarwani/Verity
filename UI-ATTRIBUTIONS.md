# Uiverse reference notes

The eight references below were opened and their rendered previews and available implementation views were inspected while building the Verity interaction system. Their public pages list the examples under the MIT license. Verity uses original application styles and accessible React controls; no source snippets were copied into this repository. The references are credited here as required notices for the design work they informed.

| Creator | Reference | Considered or adapted |
| --- | --- | --- |
| catraco | [short-starfish-66](https://uiverse.io/catraco/short-starfish-66) | Restrained hover feedback informed the primary button sheen and pressed state. |
| Javierrocadev | [fuzzy-rabbit-3](https://uiverse.io/Javierrocadev/fuzzy-rabbit-3) | Reviewed for layered hover effects; Verity uses a low contrast teal interaction instead of its original colors. |
| Shubh0408, based on PriyanshuGupta28 | [heavy-puma-48](https://uiverse.io/Shubh0408/heavy-puma-48) and [spicy-starfish-71](https://uiverse.io/PriyanshuGupta28/spicy-starfish-71) | Checkbox reference reviewed; its page identifies HTML + Tailwind and credits the original CSS design. Verity keeps native keyboard-operable form controls with the app accent color. |
| rishichawda | [fluffy-robin-48](https://uiverse.io/rishichawda/fluffy-robin-48) | Toggle motion informed the small, reduced-motion-aware account status control. |
| ilkhoeri | [smooth-quail-87](https://uiverse.io/ilkhoeri/smooth-quail-87) | Card preview reviewed; its terminal styling was not used in the examination product. |
| amir_6539 | [red-duck-82](https://uiverse.io/amir_6539/red-duck-82) | Card preview reviewed; its starfield decoration was not used. |
| Cobp | [horrible-quail-18](https://uiverse.io/Cobp/horrible-quail-18) | Copy interaction inspired the explicit “Copy setup link” action for a newly created invitation. |
| gsperandio | [shaggy-kangaroo-12](https://uiverse.io/gsperandio/shaggy-kangaroo-12) | Loader preview reviewed; Verity retains a quiet CSS spinner for loading states. |

The interactions use Verity's Soft Sage & Teal palette and respect `prefers-reduced-motion`. The page links preserve attribution to the original creators and their MIT-licensed examples.
